DJ Tools Clone Setup
====================

Use this file if you cloned the repo and want to get `dj_tools_menu.bat` running correctly.

What the menu needs
-------------------

1. Windows
2. Python installed and available through the `py` launcher
3. The Python package `mutagen` available either:
   - inside `musicKeyConversion\.venv`, or
   - in the Python that `py` launches
4. The files inside `crate-digger` present if you want to use crate digger
   - especially `yt-dlp.exe`
   - `ffmpeg.exe`
   - `ffprobe.exe`
   - `fpcalc.exe`
   - `sources.txt`
   - `crawler.txt`
   - `yt-dlp.conf`


Recommended setup
-----------------

Open PowerShell in the repo root and run:

`py -m venv musicKeyConversion\.venv`

Then activate it:

`.\musicKeyConversion\.venv\Scripts\Activate.ps1`

Then install the required package:

`python -m pip install mutagen`


How to start the menu
---------------------

From the repo root:

`.\dj_tools_menu.bat`

You can also double-click `dj_tools_menu.bat` in File Explorer.


Fastest way to verify setup
---------------------------

1. Run `.\dj_tools_menu.bat`
2. Choose `5` or `6` (Camelot converter or Camelot to comments)
3. Enter a test music folder
4. Use preview mode only on the first run

If the menu opens and those options run without a Python error, your setup is good.


If Python is not installed
--------------------------

Install Python for Windows and make sure the `py` launcher is available.

Quick check:

`py --version`

If that command fails, install Python first, then repeat the setup above.


If the menu says Python is missing
----------------------------------

Try these checks:

`py --version`

`Test-Path .\musicKeyConversion\.venv\Scripts\python.exe`

What they mean:

- If `py --version` fails, Python is not installed correctly.
- If the venv path returns `False`, create the virtual environment using the commands above.


If crate digger, dedupe, or WAV->MP3 do not run
-----------------------------------------------

Menu options `3`, `4`, and `7` all rely on files inside `crate-digger\`.

Check that these exist:

- `crate-digger\yt-dlp.exe`        (option 3)
- `crate-digger\ffmpeg.exe`        (option 3, option 7 — WAV to MP3 encoder)
- `crate-digger\ffprobe.exe`       (option 3)
- `crate-digger\fpcalc.exe`        (option 4 — dedupe fingerprinting)
- `crate-digger\sources.txt`       (option 3)
- `crate-digger\crawler.txt`       (option 3)
- `crate-digger\yt-dlp.conf`       (option 3)
- `crate-digger\discover.ps1`      (option 3 — discovery crawler)
- `crate-digger\dedupe_audio.ps1`  (option 4)

If any of those are missing, the relevant menu option will not work until they are restored.

Option `7` (WAV to MP3) requires that the bundled `ffmpeg.exe` was built with the `libmp3lame` encoder. The shipped one is. If you replace it, verify with:

`.\crate-digger\ffmpeg.exe -hide_banner -encoders | findstr libmp3lame`


Clean start commands
--------------------

If you want the full setup in one place, run these from the repo root:

`py -m venv musicKeyConversion\.venv`

`.\musicKeyConversion\.venv\Scripts\Activate.ps1`

`python -m pip install --upgrade pip`

`python -m pip install mutagen`

`.\dj_tools_menu.bat`


Notes
-----

- The menu prefers `musicKeyConversion\.venv\Scripts\python.exe` if it exists.
- If that venv does not exist, the menu falls back to `py`.
- Options `5` (Camelot converter) and `6` (Camelot to comments) depend on the `mutagen` Python package.
- Options `1`, `2`, `7`, and `8` are also Python-based but only need stdlib.
- Option `3` (Crate digger) uses the executables and text files in `crate-digger`.
- Option `4` (Dedupe audio) is PowerShell-based and needs `crate-digger\fpcalc.exe` and `crate-digger\dedupe_audio.ps1`.
- Option `7` (WAV to MP3) shells out to `crate-digger\ffmpeg.exe` for libmp3lame encoding.
